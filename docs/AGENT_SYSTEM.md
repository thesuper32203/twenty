# AI agent system

This describes **product AI agents** in Twenty, separate from the repository's coding-agent skills in [SKILLS.md](../SKILLS.md). For a wider audit and runtime caveats, see [CODEBASE_AUDIT.md](CODEBASE_AUDIT.md).

## Entry and execution

1. [`AgentEntity`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent/entities/agent.entity.ts) and [`AgentService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent/agent.service.ts) manage definitions. [`AgentChatResolver`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-chat/resolvers/agent-chat.resolver.ts) exposes `chatThread`, `chatMessages`, `chatStreamCatchupChunks`, `createChatThread` and `sendChatMessage` GraphQL operations. [`AgentChatService.queueMessage`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-chat/services/agent-chat.service.ts) persists/queues messages.
2. [`RunAgentJob`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/jobs/run-agent.job.ts) invokes [`AgentRunnerService.start`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/services/agent-runner.service.ts). The runner claims a conversation, runs a turn, settles/suspends or delivers a failure, and can continue via [`ContinueAgentRunJob`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/jobs/continue-agent-run.job.ts). Workflow and database-event entry points are under [`workflow-agent-conversation.workspace-service.ts`](../packages/twenty-server/src/modules/workflow/workflow-executor/workflow-actions/ai-agent/services/workflow-agent-conversation.workspace-service.ts) and [`agent-trigger-runner.service.ts`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-trigger/services/agent-trigger-runner.service.ts).
3. [`AgentStepLoopService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/services/agent-step-loop.service.ts) performs model streaming, step limits, tool handling, usage/billing and abort. [`SdkProviderFactoryService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-models/services/sdk-provider-factory.service.ts) selects configured providers; enabled providers and credentials depend on deployment.

## Context, tools and persistence

[`AgentConversationReaderService.loadMessages`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-history/services/agent-conversation-reader.service.ts) loads persisted conversation parts; [`AgentConversationWriterService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-history/services/agent-conversation-writer.service.ts) and [`AgentTurnRecorderService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-history/services/agent-turn-recorder.service.ts) write history/turn state. Workspace entities for thread, message, message part and turn are under [`ai-history/standard-objects`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-history/standard-objects/). [`SystemPromptBuilderService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-chat/services/system-prompt-builder.service.ts) builds prompt context; [`MessagePruningService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-chat/services/message-pruning.service.ts) is the place to inspect message selection. Exact long-history truncation behavior needs scenario verification.

[`AgentToolsetService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/services/agent-toolset.service.ts) assembles tools; [`ToolRegistryService`](../packages/twenty-server/src/engine/core-modules/tool-provider/services/tool-registry.service.ts) resolves providers and execution context. Pausing and approval tools live under [`ai-agent-execution/pausing-tools`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/pausing-tools/). Check grants and workspace context at each tool provider when changing capabilities.

## Background work and recovery

Agent runs use the shared queue described in [ARCHITECTURE.md](ARCHITECTURE.md). [`AgentChatStreamRecoveryService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-chat/services/agent-chat-stream-recovery.service.ts) handles stream claims/releases and failure state. [`AgentRunPendingWakeUpHandlerService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/services/agent-run-pending-wake-up-handler.service.ts) resumes persisted wake-ups; [`pending-wake-up-sweep.cron.job.ts`](../packages/twenty-server/src/engine/core-modules/pending-wake-up/crons/jobs/pending-wake-up-sweep.cron.job.ts) sweeps them. [`AgentRunnerService`](../packages/twenty-server/src/engine/metadata-modules/ai/ai-agent-execution/services/agent-runner.service.ts) includes busy-conversation retry, suspension, continuation and failure delivery paths. End-to-end recovery after process loss and provider outage is **unverified** by source inspection alone.
